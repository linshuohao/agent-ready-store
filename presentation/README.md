# 展示与答辩

直接用浏览器打开 `index.html`，无需安装依赖或启动商城。展示主线 10 屏约 24 分钟，备查 4 屏按需展开。也可以从仓库根运行 `python3 -m http.server 4173 --bind 127.0.0.1`，访问 `http://127.0.0.1:4173/presentation/`。

- 左侧切换主讲与备查，各自保留本次浏览的位置；URL hash 可直达章节。
- 左右方向键翻页，M 回主讲，B 进入备查。
- 内容直接面向共享屏幕阅读；各屏展开设计理由、实现、取舍与证据，不包含私人提示或追问清单。
- 证据使用仓库相对路径；请保留完整仓库目录。浏览器可能显示或下载 Markdown / 源码文件，取决于打开方式。
- 本地商城需另按根 README 启动。GitHub 链接需要网络和仓库访问权限，本展示不复制或发布原始作业材料。

`slides.js` 维护展示摘要、图示和证据入口；`app.js` 处理导航，`style.css` 维护视觉。正式业务契约仍以项目决策与 OpenSpec 为准。历史验证记录不是本展示版本的重新测试；真实购物完整录影与现场开发演练仍待补充。
