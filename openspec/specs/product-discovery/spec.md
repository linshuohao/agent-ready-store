# product-discovery Specification

## Purpose

使 Human 与外部 Agent 能以一致、确定且有界的查询浏览商品、详情与全部评论，获得当前公开可购买状态；保留来源数据边界并隔离内部经营信息，为后续购物切片提供可验证的只读入口。

本文为已批准的 S1 增量；细化参数见 Design，批准与实施授权来源见 Proposal。

## Requirements

### Requirement: 有界且确定的商品查询

系统 SHALL 支持空条件浏览、文本查询与必要筛选，先筛选再按原始推荐分数降序、同分确定性排序，分页返回商品摘要和继续读取信息；不得毛利加权或无边界返回全部商品。相同目录、库存和查询条件产生相同结果。

#### Scenario: 查询与稳定分页
- **WHEN** 目录、运行库存和查询条件保持不变，调用者连续翻页，包括同分商品、空结果和末页
- **THEN** 顺序稳定、页边界明确，无遗漏或重复；筛选作用于排序之前

#### Scenario: 翻页间可购买状态变化
- **WHEN** 可购商品筛选的连续分页请求之间运行库存发生变化
- **THEN** 每页按当次库存决定候选集合与总数，不保证跨页无遗漏或重复；库存变化不等于目录版本变化，调用者可从第一页重新查询

#### Scenario: 非法查询
- **WHEN** 查询输入格式错误、超出资源边界或选择不支持的排序
- **THEN** 返回明确校验错误，不静默截断或放宽条件

### Requirement: 身份、详情与公开投影

系统 SHALL 按唯一商品 ID 区分同名商品，列表只返回必要摘要，详情返回基本信息、规格和评论概览而不嵌入全部评论。公开响应 MUST 使用字段白名单，不返回 margin_rate、原始 recommendation_score、服务秘密或堆栈；不存在的商品与服务故障明确区分。

#### Scenario: 同名与公开字段
- **WHEN** 查询 P001/P002 的列表和详情
- **THEN** 两商品独立保留各自身份、价格与状态，响应不泄露内部字段

#### Scenario: 不存在与技术故障
- **WHEN** 查询未知 ID 或依赖暂不可用
- **THEN** 分别返回未找到或技术失败，不能伪装为成功空数据

### Requirement: 当前库存与异常数据保真

系统 SHALL 组合只读商品事实与持久化运行 Inventory；原始 stock 只用于首次初始化，重启不覆盖已有库存。零库存、负库存、零价格及缺 Inventory 行均可展示且不可购买，说明相应原因；不得回退到原始 stock 或通过修正原件掩盖异常。商品仅在价格和库存均正数且事实有效时标为可购买。

#### Scenario: 异常样本与缺失库存
- **WHEN** 读取零库存 P002/P016、负库存 P008、零价 P010 或缺 Inventory 行的商品
- **THEN** 保留来源值，标示售罄、库存异常、价格待确认或库存不可用，canPurchase 为 false

#### Scenario: 重启与新请求
- **WHEN** 测试环境修改运行库存后重启 API，并重新请求 Web/API/MCP
- **THEN** 已有运行库存不被 seed 覆盖，各入口读取更新后状态；不承诺跨页库存快照

#### Scenario: 首次初始化失败与再次执行
- **WHEN** 新建空库首次初始化库存在提交前失败，并在故障消除后再次执行
- **THEN** 失败不留下部分库存，重跑可完整初始化；若库内已有任意库存行，再次初始化明确拒绝且不改量或补回缺行

### Requirement: 独立评论与目录版本

系统 SHALL 按商品独立分页评论，调用者可读完全部评论；评论与描述始终作为不可信纯文本，不能改变工具权限或触发商城操作。分页携带目录版本，版本变化时明确拒绝继续拼接旧页并提示重新查询。

#### Scenario: 全部评论与注入样本
- **WHEN** 逐页读取某商品全部评论，包括 P005 的伪造指令文本
- **THEN** 评论保真、顺序稳定，无遗漏或重复，文本不触发编辑、签发或下单

#### Scenario: 目录更换
- **WHEN** 使用旧目录版本继续分页
- **THEN** 得到目录已变化的错误，重新开始查询，不混合不同版本结果

### Requirement: Web 商品发现可用性

系统 SHALL 在商品列表和详情提供可读首屏、搜索筛选分页与独立评论读取；列表查询可从 URL 恢复。展示加载、空结果、未找到与失败状态；切换查询或商品时不混入迟到结果。沿用批准的响应式与基本无障碍要求，可购买状态为当前快照而非库存保证。

#### Scenario: 查询导航与评论隔离
- **WHEN** 快速切换查询、筛选后换页或前后退，以及从商品 A 切换到 B 读取评论
- **THEN** URL 与所示结果一致，筛选变化归零分页，旧请求不覆盖新结果，A 评论不追加到 B

#### Scenario: 页面基本可用性
- **WHEN** 在桌面或移动宽度通过键盘浏览列表和详情
- **THEN** 核心内容与状态可读，控件有标签和可见焦点，错误与空结果可区分且可重试

### Requirement: HTTP 与真实 MCP 共享只读语义

系统 SHALL 通过 HTTP 和 Nest MCP 的 search_products、get_product、list_product_reviews 共享查询用例、校验与公开投影；协议包装不同不改变业务结果或错误含义。MCP MUST 校验服务身份及适用 Host/Origin，拒绝越权或非法请求。S1 验收包含真实 Codex 连接及三个工具调用，不能以模拟客户端替代。

#### Scenario: 跨入口一致
- **WHEN** 同一目录/库存下对两个入口发送相同正常及异常查询
- **THEN** 数据、分页、字段过滤与业务错误语义一致，均无交易副作用

#### Scenario: 真实 Host 与拒绝边界
- **WHEN** Codex 使用有效配置调用三个只读工具，或请求使用无效身份/不允许的 Host/Origin
- **THEN** 有效调用成功完成搜索、详情与评论读取；不允许请求被拒绝，记录真实运行结果而非伪造通过
