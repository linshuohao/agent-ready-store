# Spec Delta

## MODIFIED Requirements

### Requirement: 当前库存与异常数据保真

系统 SHALL 组合只读商品事实与持久化运行 Inventory；原始 stock 只用于首次初始化，重启不覆盖已有库存。零库存、负库存、零价格及缺 Inventory 行均可展示且不可购买，说明相应原因；不得回退到原始 stock 或通过修正原件掩盖异常。正常商品可售量为quantity减reservedQuantity，未物化释放继续保守计入；商品仅在价格和可售量均正数且事实有效时标为可购买。实际库存与预留异常不以零值掩盖。

#### Scenario: 异常样本与缺失库存
- **WHEN** 读取零库存 P002/P016、负库存 P008、零价 P010 或缺 Inventory 行的商品
- **THEN** 保留来源值，标示售罄、库存异常、价格待确认或库存不可用，canPurchase 为 false

#### Scenario: 重启与新请求
- **WHEN** 测试环境修改运行库存后重启 API，并重新请求 Web/API/MCP
- **THEN** 已有运行库存不被 seed 覆盖，各入口读取更新后状态；不承诺跨页库存快照

#### Scenario: 首次初始化失败与再次执行
- **WHEN** 新建空库首次初始化库存在提交前失败，并在故障消除后再次执行
- **THEN** 失败不留下部分库存，重跑可完整初始化；若库内已有任意库存行，再次初始化明确拒绝且不改量或补回缺行

#### Scenario: 预留消费与释放投影
- **WHEN** 新订单预留、支付消费预留或取消/到期物化释放后重新查询
- **THEN** 所有入口按同一已提交可售量投影；预留使可售减少，消费不重复减少可售，释放使可售恢复；到期但未物化不提前增加可售，不混淆实际剩余量与可售量
