# Proposal

## Why
真实购买准备中，工具说明要求建单后补展示搜索结果，产生额外卡片。模拟环境、精确筛选及失败恢复说明不足，使 Agent 容易误述交易和修错。

## What Changes
- 以用户最终目标区分搜索、加购、购买、查单和取消；已授权自选不重复选型，建单成功结束本轮展示。
- 每轮至多一次最终展示调用，展示失败不自动重开；预算/规格优先无UI预检。
- 明确模拟商店，无真实扣款或物流；在 MCP 返回中标注环境。
- 明确分类/品牌精确匹配、规格原文断言与既有整行数量边界。
- 为预算/规格拒绝补公开约束详情，为 MCP 错误补恢复指引，保留原错误码和 retryable 含义。

## Capabilities
### New Capabilities
无。
### Modified Capabilities
- `agent-shopping`: 工具意图指引、模拟环境、参数边界及错误恢复。

## Impact
MCP adapter、购物服务的约束错误详情、共享错误类型及接入指南；无数据库迁移、依赖增加、计价/库存/支付规则变化。部分数量结算不在范围内。
