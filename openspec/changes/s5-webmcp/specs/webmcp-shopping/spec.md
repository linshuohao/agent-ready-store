# Spec Delta

## Purpose

让浏览器 Agent 通过商城主动注册的页面工具完成商品发现和购物车准备，取得与当前页面一致的权威报价及 AI 优惠；明确生命周期、并发与降级边界，购买始终由 Human 在 Hosted Checkout 审阅并确认。

## ADDED Requirements

### Requirement: 页面工具与独立验收

系统 SHALL 按当前页面提供结构化搜索、商品详情/评论、加购和当前车读取/编辑工具，输入输出沿用现有商品与购物契约。不注册确认购买、提交订单或模拟点击工具。真实浏览器/Host 的发现、调用、页面反馈及购物准备闭环 MUST 独立验证，不以模拟调用或基础 MCP 成功代替。

#### Scenario: Agent 准备购物
- **WHEN** 支持所选 WebMCP API 的真实 Host 调用当前页面工具搜索、查看商品、加购并编辑
- **THEN** 返回有界公开商品信息或权威车快照与完整报价，页面同步展示结果；最终购买需要 Human 在 Checkout 重新审阅和明确点击

### Requirement: Agent 优惠及普通车接手

系统 SHALL 将 WebMCP 工具成功创建的非空有效车记为 AGENT；有合法车权限时，成功工具编辑普通车 SHALL 在同一原子更新中转换为 AGENT，递增版本并应用既有 AI 优惠。无需额外 Agent 身份认证；客户端不得通过普通建车参数任意指定来源。只读查询、工具注册或失败操作 MUST 不转换来源。

#### Scenario: 新车及同车转换
- **WHEN** 工具首次有效加购，或携有效车权限和正确版本成功保存 HUMAN 车
- **THEN** 新车或原车成为 AGENT，返回服务端折扣报价；转换保留 cartId、访问能力、创建时间和有效期，不建替代车、不扣库存

#### Scenario: 转换失败与只读
- **WHEN** 仅读取 HUMAN 车，或编辑发生过期、无权限、条目非法、版本冲突或事务失败
- **THEN** 不因该次调用转换来源；失败不保存部分内容或优惠状态，保留原意图供核对

#### Scenario: 后续 Human 编辑与完成车
- **WHEN** Human 后续编辑 AGENT 车，或工具尝试修改已完成车
- **THEN** 前者保留 AGENT 来源；后者拒绝，原订单金额与来源快照不变

#### Scenario: 旧确认与并发提交
- **WHEN** WebMCP 来源转换与持旧确认的订单提交竞争
- **THEN** 转换先提交则旧版本购买失败并要求重新审阅和新点击；订单先提交则转换拒绝，不发生按旧确认购买新报价

### Requirement: 生命周期与同页协调

系统 MUST 只注册当前有效页面能力，离页/卸载后撤销，旧请求结果不得导航或更新新车。工具与 Human 共用当前车协调；脏草稿、忙碌或结果未明时不得静默覆盖、自动合并或重复建车。恢复核对必须包含预期来源转换与条目，不能仅按相同条目误判转换已成功。

#### Scenario: 脏草稿和同时编辑
- **WHEN** 页面有未保存草稿或进行中的写请求，工具又尝试修改当前车
- **THEN** 明确返回需处理草稿或忙碌状态，不丢草稿、不并行提交同页写；跨标签页仍由服务端版本裁决

#### Scenario: 离页结果隔离
- **WHEN** A 车工具请求未返回即切到 B
- **THEN** A 结果不影响 B，不更新 B 的快照或导航

#### Scenario: 恢复读取版本未推进
- **WHEN** 转换响应丢失，成功重读的同车版本不高于原预期版本
- **THEN** 保持结果未明，不因条目相同而认定转换成功；只允许显式使用原版本、原条目和原入口恢复，不自动产生新意图

#### Scenario: 恢复读取当前符合意图
- **WHEN** 转换响应丢失，成功重读的版本高于原预期版本，且条目和 AGENT 目标来源均符合原意图
- **THEN** 报告当前符合意图并解除本次等待，不推断原请求一定成功，不再重复提交原写入

#### Scenario: Human 新版本阻断原转换
- **WHEN** 工具持版本 3 请求转换但响应丢失，另一标签页先保存为版本 4，重读条目相同但来源仍为 HUMAN
- **THEN** 返回冲突和版本 4 最新快照，解除本次结果未明等待并保留原草稿；不继续等待或重试版本 3，也不自动换版本覆盖；经显式核对并重新发起才允许新写意图

#### Scenario: 新版本条目不符合原意图
- **WHEN** 转换响应丢失，成功重读版本已推进但条目与原意图不同，无论来源是否已为 AGENT
- **THEN** 同样返回冲突及最新快照、解除本次等待并保留原草稿，不自动覆盖新条目

### Requirement: 权限、降级及创建统计

系统 MUST 保留同源防护、车级凭证、统一期限和服务端计价，浏览器不得取得 MCP 服务秘密。WebMCP 不可用时普通 Web 可操作并明确能力限制，不能冒充模式验收完成。有效 Agent 创建统计继续仅计 Agent 流程首次成功创建的有效车；HUMAN 车后续转为 AGENT 不补计创建。

#### Scenario: 不支持及越权
- **WHEN** 浏览器无 WebMCP 能力，或调用者无目标车合法权限
- **THEN** 前者保留普通购物并说明工具不可用；后者拒绝访问或转换，不泄露车快照或秘密

#### Scenario: 创建与接手分开
- **WHEN** 工具新建有效 AGENT 车并重试，或接手已有 HUMAN 车后编辑、到期或成交
- **THEN** 前者有效创建仅计一次；后者不新增 Agent 创建计数，已记录创建事实不因后续生命周期撤销
